显示接口信号规格与公式汇总

依据《显示接口信号计算器》实际代码规则整理,涵盖 7 种信号类型(eDP / MIPI D-PHY / MIPI C-PHY / LVDS / V-by-One / TTL / HDMI)的输入参数、计算公式、规格阈值与合规判定逻辑。

三eDP

水平总时序垂直总时序刷新率色深Lane

计算公式(两套,同时显示)

版本系数公式
DP 1.4×1.25DSI(bps) = 水平总时序 × 垂直总时序 × 刷新率 × (色深 × 3) × 1.25 / Lane
DP 2.0×1.05DSI(bps) = 水平总时序 × 垂直总时序 × 刷新率 × (色深 × 3) × 1.05 / Lane

结果同时显示 DP 1.4 速率 与 DP 2.0 速率(均为 Gbps/Lane)。

挡位适配

对计算出的速率,在以下挡位集合中取不小于速率的最小挡位作为适配结果;若无任何挡位 ≥ 速率,则标 超规。

接口模式支持挡位(Gbps)判定依据速率显示条件
DP(DP 1.4)1.62 / 2.7 / 5.4 / 8.1DP 1.4 速率始终显示
ALPDP(DP 1.4)1.62 / 2.16 / 2.7 / 3.24 / 3.78 / 4.32 / 5.4 / 8.1DP 1.4 速率始终显示
ALPDP(DP 2.0)8.1 / 10 / 13.5 / 20DP 2.0 速率仅当 DP 1.4 速率 > 8.1 Gbps 时才显示

判定规则:DP(DP 1.4) 与 ALPDP(DP 1.4) 按 DP 1.4 速率 匹配;ALPDP(DP 2.0) 按 DP 2.0 速率 匹配。

举例

DP 1.4 速率 = 12.39 Gbps(→ DP 2.0 速率 ≈ 10.41 Gbps):

  • DP(DP 1.4):超规(>8.1)
  • ALPDP(DP 1.4):超规(>8.1)
  • ALPDP(DP 2.0):13.5 Gbps 适用(因 12.39 > 8.1,显示该行;按 10.41 匹配)

DP 1.4 速率 = 3.39 Gbps:

  • DP(DP 1.4):5.4 Gbps 适用
  • ALPDP(DP 1.4):3.78 Gbps 适用
  • ALPDP(DP 2.0):不显示(≤8.1)

四MIPI D-PHY

水平总时序垂直总时序刷新率色深Lane

计算公式(4 组)

DSI(bps) = (水平总时序(Pixels) + 加数) × 垂直总时序(Pixels) × 刷新率(Hz) × 色深(bit) × 3 / Lane

按目标速率档位与时钟模式选择不同加数(协议开销):

速率档位时钟模式水平时序加数
< 1.5 Gbps非离散(连续时钟)+95
< 1.5 Gbps离散(Burst/突发)+190
> 1.5 Gbps非离散+145
> 1.5 Gbps离散+255

结果表与自洽高亮

4 组公式全部计算并列出;每行判定自洽性(公式档位与计算结果是否一致),自洽行高亮 适用:

  • <1.5 Gbps 档的行:计算结果 < 1.5 Gbps → 自洽;
  • >1.5 Gbps 档的行:计算结果 ≥ 1.5 Gbps → 自洽。

DSI 上限

  • 上限:2.5 Gbps/Lane(>1.5 Gbps 档的上限为 2.5 G)。
  • 取自洽行中最大速率,若 > 2.5 Gbps → 提示(warn 样式):DSI 速率 X.XX Gbps 超出上限 2.5 Gbps (>1.5Gbps );
  • 否则提示:DSI 速率在规格内(上限 2.5 Gbps/Lane)。

五MIPI C-PHY

水平总时序垂直总时序刷新率色深Lane

计算公式

像素时钟(MHz) = 水平总时序(Pixels) × 垂直总时序(Pixels) × 刷新率(Hz) ÷ 10⁶ DSI 速率(sps) = 水平总时序(Pixels) × 垂直总时序(Pixels) × 刷新率(Hz) × 3 × 色深(bit) × 1.2 / (Lane × 2.28)

固定常数:×3、×1.2、/2.28(2.28 ≈ 每符号 16/7 bit)。色深取自用户所选胶囊(默认 8 bit)。

像素时钟规格(361 平台 / 2832 芯片)

单 TTL 像素时钟上限 160 MHz;1 个 2832 = 2 个 TTL;2 个 2832 = 4 个 TTL = 平台上限。

像素时钟判定建议配置
≤ 320 MHz✅ 在规格内1 个 2832、2 个 TTL(上限 320 MHz)
320 < ≤ 640 MHz✅ 在规格内2 个 2832、4 个 TTL(上限 640 MHz)
> 640 MHz⚠️ 超规超出 361 平台规格上限(640 MHz)

DSI 符号率上限

  • 上限:1.5 Gsps/Lane(符号率,sps)。
  • DSI 速率 > 1.5 Gsps → 超规;否则在规格内。

六LVDS

水平总时序垂直总时序刷新率Link 数不使用色深

选 LVDS 时,Lane 数胶囊组切换为 Link 数:单通道(1)/ 双通道(2)/ 四通道(4)/ 八通道(8)。

计算公式

像素时钟(MHz) = 水平总时序(Pixels) × 垂直总时序(Pixels) × 刷新率(Hz) ÷ 10⁶ Single-link LVDS像素时钟 PCLK(MHz) = 像素时钟(MHz) ÷ Link 数

显示

  • 大字:Single-link LVDS 像素时钟(PCLK) = 像素时钟 ÷ Link 数
  • 小字:像素时钟(总)= 水平总时序 × 垂直总时序 × 刷新率 ÷ 10⁶

规格阈值(@0.1 MHz 步进)

按所选 Link 数对应的通道规格(以总像素时钟判定):

Link 数通道像素时钟范围等效(单 Link 基准 10–135 MHz)
1单通道 Single10 ~ 135 MHz10 ~ 135 MHz
2双通道 Dual20 ~ 270 MHz2 × (10 ~ 135)
4四通道 Quad40 ~ 540 MHz4 × (10 ~ 135)
8八通道 Octal80 ~ 1080 MHz8 × (10 ~ 135)

判定规则

总像素时钟 > 上限 → ⚠️ 超出{通道}上限(XXX MHz),建议增加通道数

总像素时钟 < 下限 → ⚠️ 低于{通道}下限(XX MHz),可减少通道数

总像素时钟 在范围内 → ✅ 在{通道}规格内(XX–XXX MHz @0.1MHz 步进)

七V-by-One

水平总时序垂直总时序刷新率色深Lane色深与 Lane 数取自用户选择

计算公式

Lane 数据速率(bps) = 水平总时序(Pixels) × 垂直总时序(Pixels) × (色深(bit) × 3) × 1.25 × 刷新率(Hz) ÷ Lane 数

×3 = RGB 三通道;1.25 = 编码开销系数(8b/10b)。

规格阈值

  • 上限:3.75 Gbps/Lane(目前最高数据速率)。
  • 每 Lane 速率 ≤ 3.75 Gbps → ✅ 在规格内;> 3.75 Gbps → ⚠️ 超规格。

📝 变更记录:旧版公式为 水平分辨率 × 垂直分辨率 × 1.2 × 30(bit) × 刷新率 / Lane(固定 30bit = 10bit×3、消隐系数 1.2);现行公式改用总时序与可选色深,系数改为 1.25。

八TTL

水平总时序垂直总时序刷新率不使用色深 / Lane,Lane 字段隐藏

计算公式

时钟频率(Hz) = 水平总时序(Pixels) × 垂直总时序(Pixels) × 刷新率(Hz) (单边沿采样,即传输速率)

采用单边沿采样,一个时钟周期传送 1 bit,故时钟频率即对应的传输速率(MHz = Mbps)。

规格阈值

  • 上限:100 Mbps(规格书标定最高)。
  • 时钟频率 ≤ 100 Mbps → ✅ 在规格内;> 100 Mbps → ⚠️ 超规格。

八续HDMI

水平总时序垂直总时序刷新率固定 10bit,Symbol per clock=1,不使用色深 / Lane

固定参数

参数值说明
色深10 bit固定
Color Depth Factor1.25固定
Symbol per clock1固定

计算公式

像素时钟(MHz) = 水平总时序(Pixels) × 垂直总时序(Pixels) × 刷新率(Hz) ÷ 10⁶ HDMI 1.4: TMDS时钟(MHz) = 像素时钟 × 1 × 1.25 HDMI 2.0: TMDS时钟(MHz) = 像素时钟 × 1 × 1.25 ÷ 4 TMDS带宽(Gbps) = TMDS时钟(MHz) × 10(固定10bit) ÷ 1000

结果展示

  • 像素时钟单独显示(大字)
  • HDMI 1.4 / 2.0 对比表格:显示各自的 TMDS时钟与 TMDS带宽
  • 表格中标注合规/超规状态
  • 底部给出总体规格判定

总体判定规则

HDMI 1.4HDMI 2.0判定
超规超规⚠️ HDMI 1.4 和 2.0 TMDS带宽均超出规格(> 18 Gbps)
超规合规⚠️ HDMI 1.4 TMDS带宽超出规格,建议使用 HDMI 2.0
合规超规✅ HDMI 1.4 合规,HDMI 2.0 超规但可通过降频使用
合规合规✅ HDMI 1.4 和 2.0 TMDS带宽均在规格内(≤ 18 Gbps)

规格阈值

  • TMDS带宽上限:18 Gbps
  • HDMI 1.4 TMDS带宽 ≤ 18 Gbps → ✅ 合规;> 18 Gbps → ⚠️ 超规
  • HDMI 2.0 TMDS带宽 ≤ 18 Gbps → ✅ 合规;> 18 Gbps → ⚠️ 超规

九交互与校验规则

计算

  • 实时计算:任一输入变化立即重算当前选中信号的结果。
  • "计算"按钮:强制校验全部所需字段(标记 touched)并重算,结果区附反馈动效。
  • 状态保留:各输入值保留在内存中,切换信号类型再切回不丢失;输入值不写 localStorage(仅 Timing 面板折叠状态经 localStorage 记忆)。

字段校验

字段规则
水平/垂直总时序、刷新率非空 · 数字 · > 0
色深胶囊枚举(8/10/12),无需校验
Lane 数胶囊枚举(1/2/4/8/16/32;MIPI D-PHY 增 3,MIPI C-PHY 增 3/6),恒为合法
Link 数(LVDS)胶囊枚举(1/2/4/8),恒为合法
  • 非法字段:输入框下方红字提示(如"请输入数值""需大于 0"),结果区显示"请先修正高亮的输入项",不输出错误计算结果。
  • 仅当前信号所需字段参与校验(如 LVDS/TTL 不校验色深与 Lane)。
